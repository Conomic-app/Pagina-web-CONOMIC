Cómo instalar CONOMIC
  1. Descarga el APK desde esta página en tu teléfono Android.
  2. Abre conomic-release.apk desde las descargas del navegador o la aplicación Archivos.
  3. Si Android solicita permiso, permite instalar aplicaciones desde el navegador o la aplicación con la que abriste el archivo.
  4. Pulsa Instalar y, al terminar, abre CONOMIC. Puedes desactivar después el permiso para instalar aplicaciones de esa fuente.

Los nombres de las opciones pueden variar según el teléfono. Si aparece un bloqueo de seguridad, escríbenos indicando el mensaje.
